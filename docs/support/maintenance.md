# Amdox ERP Support & Maintenance Guide

SLAs metrics, upgrade loops, bug fixes, and long-term project roadmaps.

---

## 1. SLA Definitions & Support Mappings
- **Critical Incidents (Severity 1)**: Target resolution under 4 hours (e.g. system down).
- **Major Issues (Severity 2)**: Target resolution under 24 hours (e.g. broken module pages).
- **Minor Bugs (Severity 3)**: Target resolution in the next release cycle.

---

## 2. Long-Term Support Roadmap
- **v1.1.0**: High-throughput queue scaling using Kafka adapters.
- **v1.2.0**: Advanced mobile ESS application updates.
- **v2.0.0**: Fully serverless edge deployments.
